How to Play

You are given a screenshot from a random WR.

Guess the category and the year of the WR!
(Currently only new file categories)

You are given more information after each guess.

The further away your guesses are (both
category and year), the more points you lose.


Possible Runs

Each category has one run from each year,
which is the final WR from that year.

If there was no WR in a given year,
that year is excluded.
