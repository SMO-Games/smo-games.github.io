How to Play

You are given a screenshot from a random WR.

Guess what category and what year the WR is from!

The further away your guesses are,
the more points you lose.

🌍 - Current Split
No number - 1st visit
⏱️ - Current Time
🙋 - Current Player

Possible Runs

Each category has one run from each year,
which is the final WR from that year.

If there was no WR in a given year,
that year is excluded.
